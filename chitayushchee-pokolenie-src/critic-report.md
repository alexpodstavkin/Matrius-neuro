# Отчёт критика (Кротос) — Читающее поколение, раунд 1 · 04.09.2026
Конверсионный потенциал: **4/10**. Статус: ТРЕБУЕТ ДОРАБОТКИ. P0 — 5, P1 — 13, P2 — 8.

**Главная проблема:** лендинг опирается на заимствованный авторитет («Федеральный проект РФ») вместо собственных
доказательств. На странице нет ни бренда, ни эксперта, ни отзывов, ни лицензии, ни одного числа с источником.

## P0
- **P0-1. «Федеральный проект РФ» без организатора.** Коммерческий продукт частной компании подан как госпроект:
  безличное «выдаётся», нет шапки/логотипа, слова «Матриус» на странице нет, подвал сведён к 5 ссылкам без юрлица и
  лицензии. Риски: ФЗ «О рекламе» ст. 5 (недостоверные сведения о продавце и официальном признании), ст. 14.3 КоАП —
  до 500 000 ₽; отказ модерации VK Ads / Яндекс.Директа; потеря доверия на звонке-продаже.
  Правка: «Всероссийский образовательный проект…» + подзаголовок «Проект образовательной платформы «Матриус»» +
  вернуть в подвал юрлицо, ИНН, лицензию.
- **P0-2. Заголовок обещает 5 навыков — их нет на странице** (после снятия карточек уроков). Правка: сделать блок
  «что получит ребёнок» из пяти пунктов-навыков.
- **P0-3. Плашка над формой «будут согласованы даты проведения»** противоречит «без расписания» и «первый урок сразу».
  Правка: «Заполните форму — доступ к первому уроку придёт на почту сразу после подтверждения заявки».
  Там же грамматика: «родителю учеников 2–8 классов» → «родителю ученика 2–8 класса».
- **P0-4. Заявки не дойдут и не посчитаются.** Эндпоинт submit.php не заведён; в форме не было целей Метрики и
  VK-пикселя; слаг подставлялся только в utm_source. → ЗАКРЫТО супервайзером (цели + слаг во все 5 полей).
- **P0-5. Ошибки формы синим** — неотличимы от фокуса. → ЗАКРЫТО (коралловая рамка + тёмная подпись + скролл к полю).

## P1 (главное)
- P1-1. Ноль социальных доказательств: нет педагога, числа учеников, отзывов, лицензии. Блок доверия нужен ДО дедлайна.
- P1-2. Нет механизма: между «беда» и «формат» пропущено «почему 5 роликов по 20 минут работают».
- P1-3. Hero не продаёт: 600px без оффера, цены, возраста и кнопки.
- P1-4. Цифры без источника; «каждый шестой» = 16,7 % против 15,4 % у ФИОКО; подозрение на подмену взрослой цифры
  детской. → ПРОВЕРЕНО и ЗАКРЫТО супервайзером: 35 % и 78 % относятся к родителям, формулировка заменена.
- P1-5. Дедлайн «сегодня+2» разоблачается при повторном визите и не говорит, что будет после даты.
- P1-6. Диапазон 2–8 классов не объяснён — точка выхода с обеих сторон.
- P1-7. «Бесплатная диагностика специалиста» не расшифрована: кто, в каком формате, что на руки, в чём подвох.
- P1-8. Список навыков повторяется трижды (Notice → Stages → Gains); обещание «запоминать» нигде не закрыто.
- P1-9. Порядок блоков: дедлайн давит раньше, чем раскрыт результат.
- P1-10. Контраст CTA ниже нормы. → ЗАКРЫТО (#4589F0, вес 500).
- P1-11. Расхождение кода с truth.md по выравниванию плашки. → снято раундом правок №4 владельца.
- P1-12. Предзаполненная галочка согласия (152-ФЗ). → ЗАКРЫТО.
- P1-13. О звонке сообщалось только после отправки. → ЗАКРЫТО (строка под кнопкой).

## P2
Канцелярит «погружение» дважды; заголовок «Что значит заниматься скорочтением сегодня?» не отвечает содержанию блока;
